# Drone

Drone is a modular drone synthesizer based on my Motherboard platform. Current version uses a Pico 2 (RP2350).

<img src="./docs/assets/drone.jpg" width="50%" />

Available on https://www.ghostintranslation.com/

This module is going to be fully open-source, but I have yet to document everything.
